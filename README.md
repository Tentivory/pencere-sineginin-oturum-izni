# Pencere Sineğinin Oturum İzni

> **Resmî uyarı:** Bu depo bilimsel bir sınır güvenliği projesidir. Gülmek yasaktır. Gülerseniz vızıltınız kayıtlara geçer.

Türkiye Cumhuriyeti Hayali İçişleri Bakanlığı Cam Sınır İdaresi, pencereye konan her sineğin *izinsiz ikamet* suçunu işlediğini tespit etmiştir. Bu yazılım, sineğe 47 satırlık resmi evrak üretir. Evrak çalışır. Sinek çalışmaz.

## Neden bu kadar ciddi?

Çünkü cam bir huduttur. Hudut şakaya gelmez. Sinek gelince gelir ama evrak gelmeden gelmez. Bu cümle hukukçular tarafından onaylanmamıştır çünkü hukukçu sinek henüz atanmamıştır.

## Kurulum

```bash
python3 sinegin_oturum_izni.py
python3 sinegin_oturum_izni.py --ad "Cama Konan Celal" --kanat 2 --db 38 --cam "mutfak" --gun 7
```
